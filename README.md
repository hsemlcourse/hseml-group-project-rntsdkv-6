## Описание задачи

По тексту новой задачи необходимо ранжировать разработчиков по степени релевантности для назначения на эту задачу.

**Входные данные:**
- Текст описания задачи (`issue_desc`)
- Профили разработчиков (исторические данные по Jira-задачам и GitLab-коммитам)
- Структурные признаки сотрудников (должность, специализация, опыт)

**Выходные данные:**
- Ранжированный список разработчиков с оценками релевантности
- Топ-5 кандидатов для назначения на задачу

**Задача:** Ранжирование (Ranking) / Рекомендательная система

**Датасет:**
- Внутренние данные Банка (DataDetective, Greenplum)
- 3 таблицы:
  - `employees.csv` — сотрудники (14 226 записей, 11 признаков)
  - `jira_issues.csv` — Jira-задачи (100 000 записей, 6 признаков)
  - `gitlab_commits.csv` — GitLab-коммиты (100 000 записей, 7 признаков)

**Целевая метрика:**
- **Recall@5** (основная) – доля задач, где реальный исполнитель попал в топ-5 рекомендаций
- **MRR (Mean Reciprocal Rank)** — средняя обратная позиция правильного ответа
- **NDCG@5** – нормализованная дисконтированная кумулятивная выгода
